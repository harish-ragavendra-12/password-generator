# Password Generator

A simple password generator built using Python.

This program generates random passwords based on user-selected options such as:
- Letters only
- Letters and numbers
- Letters, numbers, and symbols

## Features

- Random password generation
- Multiple password options
- Fixed password length
- User menu selection
- Invalid option handling

## Concepts Used

- Functions
- Loops
- Conditional statements
- Random module
- String handling
- User input handling

## Technologies

- Python 3

## How to Run

1. Clone the repository

```bash
git clone https://github.com/harish-ragavendra-12/password-generator.git
```

2. Open the project folder

```bash
cd password-generator
```

3. Run the program

```bash
python main.py
```
